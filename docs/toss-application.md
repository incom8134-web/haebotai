## 4. 대표자만 할 수 있는 일

1. **토스페이먼츠 전자결제 신청** (1절 값 사용). 문의 1544-7772, support@tosspayments.com.
2. **제출 서류** (법인 기준 일반적인 목록 · 토스 안내로 최종 확인):
   사업자등록증 사본, 법인 등기사항전부증명서, 법인 인감증명서(발급 3개월 이내), 대표자 신분증 사본, 법인 명의 정산 통장 사본, 계약서(법인 인감 날인 또는 전자계약).
3. **구매안전서비스 이용확인증** 발급을 토스에 요청(계약 후 발급).
   디지털 콘텐츠 판매는 발급이 면제될 수 있으나 구청마다 요구가 다르므로 미리 받아 두는 것을 권장.
4. **통신판매업 신고**: 정부24 온라인 신고 또는 부산진구청 방문.
   준비물: 사업자등록증, 법인 등기사항증명서, 구매안전서비스 이용확인증. 처리기간 약 1~3영업일, 등록면허세 연 약 4만 원대(**추정**).
5. 신고번호를 받으면 토스 상점관리자에 등록하고, 개발 측에 번호를 전달(`BUSINESS.mailOrderNumber`에 입력).
6. 라이브 키 발급 후 대표가 직접 Vercel에 입력 (5절).
